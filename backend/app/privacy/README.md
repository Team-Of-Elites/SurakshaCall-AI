# Privacy Module

This module ensures that SurakshaCall AI adheres to its strict privacy guarantees. It handles redaction of sensitive data and enforces retention rules before any data touches the database.

## Components

### Input
- **Raw Transcripts**: Generated by the ASR engine (e.g., faster-whisper), containing potentially sensitive PII like OTPs or bank account numbers.
- **Session State**: Determines whether the system is in `EVALUATION` or `MAXIMUM_PRIVACY` mode.

### Output
- **Redacted Transcripts**: Safe text where PII is replaced with placeholders (e.g., `[OTP_REDACTED]`).
- **Privacy Status Payloads**: JSON events sent to the frontend dashboard to visually confirm to the user that memory buffers are cleared and data is safe.

### Execution & Use
- **`redaction.py`**: Uses pre-compiled regex patterns tailored for Indian contexts (like Aadhaar and PAN formats) to scrub text. The `Redactor.redact_transcript(text)` method must be called *before* passing text to any repository function.
- **`retention.py`**: Manages the `RetentionManager`. In `MAXIMUM_PRIVACY` mode, it returns `False` for saving transcripts, explicitly blocking database writes for those records.
- **`status.py`**: Generates a standard dictionary using `get_privacy_status_payload()` which can be emitted over WebSockets to Palak's frontend dashboard.
